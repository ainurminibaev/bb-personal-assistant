# Хранилище доступов агента (`vallis-secret`)

Пароли, ключи и входы агента — по зашифрованному файлу на ключ (sops + age), без службы. Значения не
печатаются. Навык агента — `.bb/skills/secrets-store`.

**Нужно на сервере:** `sops` (3.9 или новее), `age` и `age-keygen`, Python 3.

**Поставить вручную** (до шага установщика), под учёткой агента:
1. Скопировать `deploy/vallis-secret` в `~/.local/bin/`.
2. `vallis-secret init` — ключ age в `~/.config/vallis/age.key` (0600) и папки `~/.local/share/vallis/secrets/{own,org}` (0700);
   печатает публичный ключ учётки.
3. Публичные ключи администратора — по строке в `~/.config/vallis/admin.recipients`: тогда всё, что кладёт агент,
   администратор тоже может расшифровать (резервная копия, перенос).

**Проверить:** `vallis-secret put CHECK --generate --what проверка`, `vallis-secret list --json` — запись есть,
значения нет; `vallis-secret run CHECK -- sh -c 'test -n "$CHECK"'` — код 0; `vallis-secret remove CHECK`.

Ключи организации кладёт в `org/` установщик (следующий шаг); агент их использует, но не удаляет.
Устройство и угрозы — проект С37 в мастерской платформы.
