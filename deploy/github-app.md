# GitHub под именем сотрудника

Коммиты, issue и PR сотрудника идут от его GitHub App: автор — `<slug>[bot]`, GitHub показывает их как сделанные
приложением. Токен выпускается на 1 час в момент запроса и нигде не хранится.

1. **Создать App** в организации команды — это делает человек: GitHub требует, чтобы условия принял человек.
   Права: Contents, Issues, Pull requests — запись; Metadata — чтение; Members — запись, только если сотрудник
   должен приглашать людей (правило «только с согласия владельца» — в его инструкциях). Установить на нужные репозитории.
2. **Положить ключ** на сервер сотрудника: `~/.secrets/github-app/private-key.pem`, владелец — пользователь
   сотрудника, права 0600. Несекретные ID — `~/.config/github-app/app.json` (`app_id`, `slug`, `org`, `bot_user_id`).
   При создании через manifest flow: `EMPLOYEE_GH_ORG=<org> deploy/employee-gh convert` (код — на вход).
3. **Поставить инструмент:** скопировать `deploy/employee-gh` в `~/.local/bin/` пользователя сотрудника
   (нужен Python-пакет `cryptography`), затем `employee-gh setup-git` — автор коммитов `<slug>[bot]`
   и помощник учётных данных git.
4. **Проверить:** `employee-gh check` — App, установка, репозитории и права, без секретов; затем черновой PR
   от имени бота.
