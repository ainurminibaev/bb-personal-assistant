# Project integrations

Start with the tools and skills actually available in this session and those explicitly assigned by the owner. Apply a skill's instructions to its task. Use an MCP tool for a specific operation.

| Capability | Connect | Verify |
| --- | --- | --- |
| Google Drive | Use the installed connector's sign-in for the selected account. If missing, describe an option available in this installation. | Read the title of a designated test file. |
| Project browser | Use the browser control tool and profile assigned to this project. | Open the test page and read its title. For downloads, verify the saved file. |
| Custom MCP or skill | Confirm its source and access scope. Use BB skills for skills and the selected provider's project settings for MCP servers. | Run the skill's example or discover the MCP tools and perform an authorized read. |

Report an available integration as available to connect. When it requests login, give the owner its normal sign-in page or button. Wait for human sign-in and retry in the same project. Report a verified connection with the operation that succeeded. For revoked access, offer sign-in again. Distinguish a network failure from a missing file.

A personal browser profile or Drive account requires explicit assignment before team use. Enter keys and login codes through the normal authorization form. Preserve other integrations and individual settings during updates.

## Browser choice

For reading public pages, start with Obscura if available to this project. Continue in Chromium if the page or required data is unavailable. Use Chromium with the designated profile for signed-in pages, downloads, form submissions and complex visual checks. For a simple screenshot, use the current browser. Keep the same project's profile when switching engines. Verify the state of a submitted form before retrying. If a required browser or profile is missing, specify what must be connected.
