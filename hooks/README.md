# Хук гостевых тредов

`guest-thread-guard.py` — проверка перед каждой командой агента (PreToolUse) для Codex и Claude Code.

**Зачем.** В BB нет права треда: любой тред под пользователем помощника или сотрудника может читать
и направлять другие треды через `bb`. Тред, который разговаривает с группой или с человеком, кроме владельца,
должен работать со всеми навыками, MCP, файлами и командами, но без управления самим BB.

**Что считается гостевым тредом.** Тред, который сам или через предка привязан мостом Telegram к теме группы
или к личке человека. Темы, где владелец работает один, гостевыми не считаются. Признак мост хранит
в своей базе. Хук читает её только на чтение, менять мост для этого не нужно.

**Что закрыто в гостевом треде.** Любой вызов `bb`, кроме `bb status`, `bb voice transcribe`
и `bb telegram-projects search-history`, а также любые пути к каталогу данных BB (`.bb-…`, `bb.db`,
`thread-storage`). Причина отказа возвращается агенту.

**Ограничение.** Хук проверяет команды, а не намерения. Поэтому к нему добавляются правило в инструкциях
и проверочные сценарии.

## Подключение

Скрипт кладётся в рабочую папку проекта, например в `.bb/hooks/guest-thread-guard.py`. Одинаковое описание
нужно в двух местах:

- Codex — `.codex/hooks.json` в корне проекта;
- Claude Code — раздел `hooks` в `.claude/settings.json`.

```json
{
  "hooks": {
    "PreToolUse": [
      {"matcher": "*", "hooks": [{"type": "command", "command": "python3 .bb/hooks/guest-thread-guard.py", "timeout": 30}]}
    ]
  }
}
```

## Одобрение

- **Claude Code** запускает хук проекта без отдельного одобрения.
- **Codex** запускает новый или изменённый хук только после одобрения его отпечатка.
  - На машине с плагином BB `codex-hook-trust` владелец одобряет его карточкой «Codex hooks» вверху треда Codex.
  - Агент сам хук не одобряет.
  - На сервере сотрудника этого плагина пока нет. До его установки владелец одобряет хук один раз
    в интерактивной сессии Codex под пользователем сотрудника, командой `/hooks`. Каждое изменение хука
    требует одобрения заново, пока отпечаток не совпадёт.
- **Без интерфейса BB.** `python3 setup.py … --allow-guest-guard` одобряет только этот хук для рабочей папки
  штатным вызовом Codex (`hooks/approve-guest-guard.py`, те же вызовы, что делает карточка). Запускает тот,
  кто ставит установку, — это его решение; другие хуки не трогаются. После изменения хука — повторить.
- **Как хук узнаёт тред.** Codex и Claude Code запускают хуки без переменных BB. Хук берёт идентификатор
  сессии агента из входных данных и находит тред по записям BB (только чтение). Путь к данным BB установщик
  кладёт рядом с хуком: `guest-thread-guard.json`.
- **Проверка после одобрения.** В гостевом треде попросить список тредов и текст лички владельца — отказ.
  В треде владельца `bb thread list` работает.
